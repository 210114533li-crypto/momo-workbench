📖 《指数基金投资指南》

今天阅读重点：第三章 — 指数基金的分类与选择

  • 宽基指数 vs 行业指数：沪深300、中证500等宽基指数覆盖面广、风险分散；行业指数聚焦特定赛道，波动更大
  • 规模指数与策略指数：规模指数按市值加权（如沪深300）；策略指数加入红利、低波等因子（如中证红利）
  • 选择标准：跟踪误差小（<0.5%）、规模大（>2亿）、费率低（<0.6%/年）

💬 今日对话：工作汇报

You: I'd like to give you an update on the project progress.
Manager: Sure, go ahead. How are things going?
You: We're on track. We've completed 80% of the planned tasks, and the remaining work should be done by next Wednesday.
Manager: That's good to hear. Any challenges you're facing?
You: The main issue is that we're waiting for feedback from the design team. I've already followed up with them.

📖 语法：现在完成时 (Present Perfect)

✅ We have completed 80% of the tasks.
✅ I have already followed up with the team.

结构：have/has + 过去分词。表示过去的动作对现在有影响，或持续到现在的状态。

✏️ 小练习

1. 翻译：我们已经完成了这个项目。
2. 翻译：这是我第一次做演讲。
3. 造句：用 "never + 现在完成时" 造一个句子。
